# 🎵 아리스 (Aris) - Discord 음악 봇 & 야추 다이스 게임

아리스는 Discord에서 음악 재생과 야추 다이스 게임을 즐길 수 있는 다기능 봇입니다. 친근한 한국어 인터페이스와 다양한 기능을 제공합니다.

## ✨ 주요 기능

### 🎶 음악 재생 기능
- **YouTube 음원 재생**: URL 또는 검색어로 음악 재생
- **대기열 관리**: 여러 곡을 순서대로 재생
- **재생 모드**: 
  - 한 곡 반복
  - 전체 반복
  - 랜덤 재생
- **볼륨 조절**: 실시간 볼륨 조절
- **플레이리스트**: 개인별 플레이리스트 생성 및 관리
- **재생 기록**: 히스토리 기능으로 이전에 들은 곡 다시 재생
- **날짜별 재생**: 특정 날짜에 들었던 곡들을 다시 재생

### 🎲 야추 다이스 게임
- **멀티플레이어 지원**: 최대 여러 명이 동시에 플레이
- **실시간 게임**: 버튼을 통한 직관적인 조작
- **점수 계산**: 자동 점수 계산 및 보너스 시스템
- **게임 상태 관리**: 턴제 게임 진행

### 🔧 관리 기능
- **메시지 삭제**: 관리자 권한으로 메시지 정리
- **봇 재시작**: 관리자 권한으로 봇 재시작
- **로그 시스템**: 상세한 로그 기록

## 🚀 설치 및 설정

### 필수 요구사항
- Python 3.8 이상
- FFmpeg (음성 처리용)
- Discord Bot Token

### 1. 저장소 클론
```bash
git clone <repository-url>
cd Tendo_Aris
```

### 2. 의존성 설치
```bash
pip install -r requirements.txt
```

필요한 패키지들:
- discord.py
- yt-dlp
- python-dotenv
- fuzzywuzzy
- async-timeout

### 3. 환경 설정
1. `TOKEN.env` 파일 생성:
```
DISCORD_BOT_TOKEN=your_bot_token_here
```

2. FFmpeg 경로 설정 (bot.py 116번째 줄):
```python
ffmpeg_path = r'C:\path\to\your\ffmpeg.exe'
```

### 4. 봇 실행
```bash
python bot.py
```

## 🎮 게임 조작법

### 야추 다이스 게임
1. **게임 시작**: `!야추` 명령어로 게임 생성
2. **참가**: 다른 플레이어들이 `!야추`로 참가
3. **게임 시작**: 게임장이 `!시작` 명령어 실행
4. **게임 진행**:
   - `굴리기` 버튼으로 주사위 굴리기 (최대 3회)
   - 주사위 버튼으로 고정/해제
   - `점수 기록` 버튼으로 카테고리 선택
   - `점수판` 버튼으로 현재 점수 확인

### 점수 계산
- **상단 (1-6)**: 해당 숫자의 개수 × 숫자
- **풀하우스**: 3개 + 2개 조합 → 25점
- **포카드**: 4개 이상 → 모든 주사위 합계
- **스몰 스트레이트**: 1-4, 2-5, 3-6 중 하나 → 30점
- **라지 스트레이트**: 1-5 또는 2-6 → 40점
- **야추**: 5개 모두 같은 숫자 → 50점
- **찬스**: 모든 주사위 합계
- **보너스**: 상단 합계 63점 이상 시 35점 추가

## 🔧 설정 및 커스터마이징

### 음성 설정
- **FFmpeg 경로**: `bot.py`의 `ffmpeg_path` 변수 수정
- **볼륨 기본값**: `MusicPlayer` 클래스의 `self.volume` 값 조정
- **재시도 설정**: 403 오류 방지를 위한 재시도 횟수 조정

### 게임 설정
- **타임아웃**: 버튼 응답 시간 조정
- **최대 플레이어**: 게임 참가자 수 제한 설정

### 로깅 설정
- **로그 레벨**: `logging_config.py`에서 조정
- **로그 파일**: `logs/` 디렉토리에 저장
- **로그 회전**: 10MB마다 새 파일 생성

## 🛠️ 문제 해결

### 일반적인 문제들

1. **봇이 음성 채널에 연결되지 않음**
   - 봇에 음성 채널 접근 권한 확인
   - FFmpeg 설치 및 경로 확인

2. **YouTube 영상 재생 오류**
   - 403 오류는 자동 재시도로 해결
   - 비공개/삭제된 영상은 건너뜀

3. **게임이 시작되지 않음**
   - 최소 2명 이상의 플레이어 필요
   - 게임장만 `!시작` 명령어 사용 가능

### 로그 확인
```bash
# 로그 파일 위치
logs/yacht_bot.log
```
